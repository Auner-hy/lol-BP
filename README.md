# LOL 对位识别 & Counter 英雄推荐工具

**当前版本：v1.2.0** ｜ 完整更新记录见 [CHANGELOG.md](CHANGELOG.md) ｜ [下载最新 exe](#下载免安装-exe推荐)

在英雄联盟 **BP 选将和游戏对局**过程中，自动识别对位（同路）敌方英雄，并结合
全网对位胜率推荐克制英雄；预选阶段点击英雄头像还能提前给出 **Ban 人建议**。
原生深色海克斯风格桌面窗口，双标签页实时刷新，**无需安装、双击即用**。

## 功能特性

- **BP 预选 / Ban 人建议**：选将阶段在游戏里**点击任意英雄头像**（设置选择意向，
  鼠标悬停不会触发），即可立即看到"这个英雄怕被谁克制"，方便决定 Ban 谁；
  自动过滤已被 Ban 的英雄，切换点击对象即时刷新。
- **自动对位 Counter 推荐**：识别同路敌方英雄，按对位克制幅度排序推荐
  反制英雄，前三名金 / 银 / 铜名次、彩色胜率条（绿=明显克制、青=小优、
  金=均势、灰=劣势），列表可滚动。
- **横版双标签页**：
  - **① 英雄推荐**：对位目标、敌方阵容、全路对位总览、克制 / 受克制榜；
  - **② 符文出装**：推荐符文、核心出装 / 鞋子、召唤师技能顺序。
  - **双方 10 人选齐后自动跳到符文出装页**，BP 阶段停留在推荐页。
- **敌方阵容条**：五个敌方头像加分路标签，**点击任意头像即可切换**查询目标，
  底部「↩ 恢复自动识别」可回到自动模式。
- **手动查询**：顶部搜索框支持中文名 / 英文名 / 俗称模糊搜索 + 分路选择，
  进游戏前也能提前查任意英雄。
- **窗口置顶**：可开关，默认置顶，BP 时边选边看。
- **高 DPI 清晰渲染**：自动适配 Windows 高分屏缩放（125% / 150% / 200%）。
- 英雄头像使用高清源（Community Dragon），首次出现自动下载缓存。

## 响应速度与稳定性

- **内置离线克制表 0 等待出首帧**，进入识别立刻有结果，断网也能用；
- 在线统计源（Lolalytics / Blitz）后台并行竞速拉取，拿到后**原地替换**为在线
  胜率（通常 2–4 秒，数据源标记会从"离线表"变为"在线数据"）；
- **界面不再周期性闪烁**：后台轮询时若局面没变化（状态签名相同）就跳过重绘，
  头像下载完只更新对应头像，右下角时钟独立刷新；
- 点击切换目标时界面**立即响应**，头像后台并行下载、不阻塞界面。

## 源码运行（Windows）

1. 安装 **Python 3.9 或更高版本**：<https://www.python.org/downloads/>，
   安装时勾选「Add Python to PATH」；
2. 安装依赖并启动：

   ```bash
   pip install -r requirements.txt
   python run_app.py          # 或：python -m lolcp
   ```

3. 打开英雄联盟、正常排队进游戏即可：
   - BP 选将界面**点击英雄头像**可提前获得 Ban 建议；
   - 敌方阵容以头像排列，**点击任意敌方头像**切换查询目标；
   - 也可用顶部搜索框输入任意英雄、选择分路提前查克制；
   - 双方选齐后自动跳到符文出装页。

> 想自己重新打包 exe：在装有 Python 和 PyInstaller 的电脑上双击
> `build_exe.bat`，产物 `LOLCounterPicker.exe` 直接生成在项目根目录。

## 工作原理（全部只读，安全无注入）

| 阶段 | 识别方式 | 数据通道 |
|------|----------|----------|
| BP / 选将 | 读取客户端本地 LCU 接口 | `https://127.0.0.1:<端口>/lol-champ-select/v1/session` |
| 游戏进行中 | Riot 官方 Live Client Data API | `https://127.0.0.1:2999/liveclientdata/allgamedata`（[官方文档](https://developer.riotgames.com/docs/lol)） |

**LCU 凭证自动获取（多级降级，国服 / 官服均适用）：**

1. 安装目录下 `lockfile`（含端口和随机密码）；
2. 客户端 UX 启动日志中的 `--remoting-auth-token` 和 `--app-port`
   （国服部分环境 lockfile 损坏时的主通道）；
3. 端口与 `netstat` 中 LeagueClient.exe 实际监听端口交叉验证；
4. 进程定位 + 盘符浅扫描兜底。

每组凭证都会发起一次只读请求实测，验证通过才使用。

这与 OP.GG、WeGame 英雄联盟助手、Blitz 等工具的原理相同：

- **只发 GET 只读请求**，不修改客户端 / 游戏任何状态；
- **不读取游戏进程内存、不注入 DLL、不模拟键鼠、不抓包改包**；
- 数据只在本机 `127.0.0.1` 回环内传输，不接触账号密码；
- 不依赖 Vanguard 敏感权限。使用第三方工具仍存在理论风险，请自行评估。

### 对位数据来源（自动降级）

1. **Lolalytics**（默认）——对位页面数据，按翡翠及以上段位、当前版本统计；
2. **Blitz.gg**——备用公开统计源；
3. **内置离线克制表**——完全断网时兜底，覆盖五个位置的常见英雄。

> WeGame / 101.qq.com 的"对位克制"数据没有公开 API，本工具使用公开统计源
> 替代，胜率口径接近。数据缓存保存在 `~/.lol_counter_picker/cache/`。

```
lol_counter_picker/

    ├── live_api.py         # Riot 官方 Live Client Data API（游戏内识别）
    ├── matchup.py          # 对位数据抓取 + 符文出装 + 推荐引擎
    ├── lanes.py            # 分路归类与别名归一
    ├── offline_data.py     # 离线克制表（断网兜底）
    ├── engine.py           # 状态机：轮询客户端、产出当前局面快照
    └── app.py              # Tkinter 桌面窗口（双标签页 / 头像 / 胜率条）
```

## 已知限制

- **排位 / 征召模式**：位置已分配，自动定位同路敌人，体验最完整；
- **盲选模式**：敌方锁定前看不到英雄（游戏机制限制），锁定后可点击切换查看；
- 大乱斗等无分路模式按"全体敌人"展示，分路判断可能不准；
- 统计站点偶尔改版可能导致解析失效，离线表始终可用。
